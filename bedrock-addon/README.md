# Bedrock Analyzer UI Pack

A Minecraft Bedrock behavior/resource pack using @bedrock-core/ui. This pack provides a separate in-game analyzer UI; it does not replace or modify the official Minecraft main menu.

## Structure
- BP/scripts/main.ts — UI entry point
- RP/manifest.json — resource pack metadata
- BP/manifest.json — behavior pack metadata
- screens/main.screen.tsx — analyzer screen

Install the matching @bedrock-core/ui render pack from the same release as the library, as required by the upstream project.
