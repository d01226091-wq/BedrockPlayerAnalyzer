# BedrockPlayerAnalyzer

Android-приложение-компаньон для Minecraft Bedrock 1.26.40.5.

## Что уже есть
- Minecraft-подобная тёмная панель аналитики.
- Хранение игроков и истории между запусками приложения.
- Индикаторы: 🟢 низкий риск / 🟡 требуется проверка / 🔴 подозрительно.
- Наблюдаемые сигналы: необычная скорость, наведение, удары, резкие движения.
- Разрешение MediaProjection для анализа экрана.
- Плавающий overlay поверх Minecraft.
- GitHub Actions автоматически собирает debug APK.

## Важное ограничение
Приложение не получает доступ к устройству другого игрока и не может достоверно определить установленный чит только по экрану. Поэтому результат — поведенческая оценка, а не доказательство.

## Сбор APK без AndroidIDE
1. Открой вкладку **Actions** в GitHub.
2. Открой workflow **Build Android APK**.
3. После успешной сборки открой запуск workflow.
4. В разделе **Artifacts** скачай **bedrock-player-analyzer-debug**.

## Локальная сборка
Требуется Android SDK с API 35 и Gradle 8.9+.

`gradle :app:assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`
